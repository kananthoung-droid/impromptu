# ស៊េរី «ខាងមុខ ខាងក្រោយ ក្រុមតែមួយ» — ៥ ភាគ × ~២ នាទី

ឯកសារ `.txt` នីមួយៗ គឺជា script សុទ្ធ សម្រាប់ Impromptu (**⋯ → នាំចូលឯកសារអត្ថបទ**)។
ខ្ញុំអត់ដាក់ស្លាក [HOOK] / [PREP] ក្នុង script ទេ ព្រោះ teleprompter នឹងបង្ហាញវា ហើយវាចូលក្នុង captions ដែរ។ រចនាសម្ព័ន្ធនៅខាងក្រោមនេះ។

## បច្ចេកទេសដែលប្រើ
- **Hook** — ៣ ទៅ ៥ វិនាទីដំបូង ហើយភាគនីមួយៗប្រើ hook ផ្សេងគ្នា។ ពាក្យស្វាគមន៍មកក្រោយ hook ជានិច្ច។
- **PREP** — **P**oint (ចំណុច) → **R**eason (ហេតុអី) → **E**xample (ឧទាហរណ៍/សេនារីយ៉ូ) → **P**oint (បិទដោយចំណុចដដែល)។ មួយភាគ មានចំណុចតែមួយ។
- **Open loop** — ចុងភាគ ១–៤ បើកសំណួរទុក ដើម្បីឲ្យគេចាំមើលភាគបន្ទាប់។
- **Callback** — ឧទាហរណ៍អំពូលភ្លើងក្នុង EP1 ត្រឡប់មកវិញក្នុង EP5។
- **Rule of three / ផ្ទុយគ្នា** — «មានបីយ៉ាង», «អត់មែន… តែ…», «របាំង → ស្ពាន»។
- **CTA** — EP1 និង EP5 ឲ្យ comment / share។

| ១ | Quote ឈឺចិត្ត «…យកលុយឯណាបើកប្រាក់ខែ?» | អត់មែនរឿងតម្លៃ តែជារឿង «ខាងណាត្រូវគេមើលឃើញជាង» | ប្រាក់ខែយឺតមួយថ្ងៃ ពេញ group Telegram · អំពូលភ្លើង | Deal ១០ ម៉ឺន តែខាត? |

| ៤ | ចម្ងល់ «ពាក្យមួយម៉ាត់ធ្វើឲ្យ Back Office បាត់តម្លៃ» | ពី «របាំង» ទៅជា «ស្ពាន» | Legal↔BD · HR↔Operation (និយាយមុន/ក្រោយ) | ៥ រឿងធ្វើបានថ្ងៃច័ន្ទ |

## គន្លឹះពេលថត
- ក្រោយ hook ឈប់ ១ វិនាទី មុននិយាយបន្ត។
- កន្លែងមាន «…» ឈប់បន្តិច។ ពេលអាន quote «…» សូមដាក់សំឡេងដូចតួអង្គ តែកុំឲ្យដូចកំពុងចំអកក្រុមណាមួយ។
- ល្បឿនប្រហែល ១៣០–១៤០ wpm ឬប្រើរបៀប **«តាមសំឡេង»**។
- លេខ ១០ ម៉ឺន និង ២ ម៉ឺនដុល្លារ គ្រាន់តែជាឧទាហរណ៍ មិនមែនស្ថិតិទេ។ Value Chain គឺមកពី Michael Porter សៀវភៅ *Competitive Advantage* (១៩៨៥)។
