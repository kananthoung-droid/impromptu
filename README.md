# Impromptu — Teleprompter Camera

Record yourself on your phone while your script scrolls right under the camera lens.
Works on **iPhone (Safari)** and **Android (Chrome)**, installs to the Home Screen like a normal app,
works offline, and keeps every video on your own phone. English and ខ្មែរ.

## ភាសាខ្មែរ — របៀបដំឡើង និងប្រើប្រាស់

### ដំឡើងលើ iPhone
1. បើកតំណភ្ជាប់របស់កម្មវិធីនៅក្នុង **Safari**។
2. ចុចប៊ូតុង **Share** (ប្រអប់មានព្រួញឡើងលើ) → ជ្រើស **Add to Home Screen** → **Add**។
3. បើក **Impromptu** ពីអេក្រង់ដើម (Home Screen)។ ពេលសួរ សូមចុច **Allow** សម្រាប់កាមេរ៉ា និងមីក្រូហ្វូន។

### ដំឡើងលើ Android
បើកតំណក្នុង **Chrome** → ចុចម៉ឺនុយ **⋮** → **Install app** (ឬ **Add to Home screen**)។

### របៀបប្រើ
1. ចុច **បង្កើតថ្មី** រួចវាយ ឬបិទភ្ជាប់អត្ថបទរបស់អ្នក។
2. ចុច **ថតវីដេអូ**។ កែល្បឿនដោយប៊ូតុង **− / +** (ពាក្យក្នុងមួយនាទី) ឬចុច ⚙︎ សម្រាប់ទំហំអក្សរ គម្លាតបន្ទាត់ ពុម្ពអក្សរ ការរាប់ថយក្រោយ គុណភាពវីដេអូ…
3. ចុចប៊ូតុង **ក្រហម**។ បន្ទាប់ពីរាប់ថយក្រោយ ៣ វិនាទី អក្សរនឹងរំកិលឡើងដោយខ្លួនឯង។ សូមអានបន្ទាត់ភ្លឺនៅខាងលើ (នៅជិតកែវកាមេរ៉ា)។
4. **ចុចលើអក្សរ** ដើម្បីផ្អាក/បន្តការរំកិល។ **អូសអក្សរ** ដើម្បីថយក្រោយ ឬទៅមុខ។ ប៊ូតុង **‖** ផ្អាកការថតទាំងស្រុង។
5. ចុច **■** ដើម្បីបញ្ចប់។ វីដេអូត្រូវបានរក្សាទុកក្នុងកម្មវិធី។
6. ចុច **នាំចេញ** → **Save Video** ដើម្បីដាក់វីដេអូក្នុង **Photos**។

**ចំណងជើងរង (Captions)**: នៅទំព័រវីដេអូ ចុច **ចំណងជើងរង** ដើម្បីមើល ទាញយកឯកសារ .srt ឬបង្កើតវីដេអូដែលមានអក្សររត់ពីក្រោម។

## English — install & use

### Install on iPhone
1. Open the app link in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Open **Impromptu** from your Home Screen and tap **Allow** for camera and microphone.

### Install on Android
Open the link in **Chrome** → **⋮** menu → **Install app** (or **Add to Home screen**).

### Use it
1. **Create New** → type or paste your script.
2. **Record** → set the speed with **− / +** (words per minute) or tap ⚙︎ for text size, spacing, font, countdown, quality…
3. Tap the **red button**. After the countdown the text scrolls by itself; read the bright lines at the top, right under the lens.
4. **Tap the text** to hold/continue scrolling, **drag** it to move back or forward. **‖** pauses the recording.
5. Tap **■** to finish — the take is saved.
6. **Export** → **Save Video** puts it in Photos.

Extras: **Voice** scroll mode (text moves only while you speak), **Captions** (.srt file or a captioned copy of the video, timed from the scrolling), **Mirror** copy, rename/rotate takes, Khmer + English UI, light/dark theme, works with Bluetooth page-turner remotes.

### Good to know
- Videos are stored only on the device. Export the ones you want to keep.
- iPhones record H.264/AAC `.mp4` (opens everywhere). Android/desktop Chrome records `.mp4` or `.webm` depending on the browser.
- If a recording ever comes out empty on iPhone, swipe the app away, reopen it and try again (a known iOS Home Screen issue), and keep iOS up to date.

## For developers

Plain HTML/CSS/JavaScript (ES modules), no build step, no dependencies.

```
index.html              app shell + iOS meta tags
manifest.webmanifest    install info
sw.js                   offline cache (bump VERSION on every release)
css/                    styles + self-hosted fonts (OFL)
js/main.js              boot, router, service worker
js/prompter.js          the scrolling text engine (wpm-based)
js/media.js             camera, MediaRecorder, audio meter, voice gate
js/captions.js          captions from the scroll log (.srt)
js/process.js           on-device mirror / rotate / burned-in captions
js/screens/*.js         home, editor, recorder, review (takes), settings
```

Run locally: `node dev/serve.mjs 5173` from the parent folder, then open http://localhost:5173 (camera works on localhost).
Release: change `VERSION` in `sw.js` (and `APP_VERSION` in `js/main.js`), then push — GitHub Pages serves it over HTTPS.
